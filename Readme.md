# 🍽️ TPV Restaurante - Terminal Punto de Venta Táctil

Sistema de Terminal Punto de Venta (TPV) táctil para la gestión de bares y restaurantes desarrollado en **C#** y **WPF (.NET 8)**.

---

## 📸 Descripción General

Aplicación de escritorio optimizada para pantallas táctiles que permite la gestión ágil de comandas, diseño personalizado de sala con función de *Drag & Drop*, facturación e impresión/guardado automático de tickets.

---

## 🚀 Características Principales

* 🗺️ **Plano de Sala Dinámico (Drag & Drop):** Diseña y distribuye mesas y barras en tiempo real arrastrando los elementos en el plano.
* 🍔 **Menú Interactivo por Categorías:** Clasificación dinámica de productos (Primeros, Segundos, Postres y Bebidas).
* 🔒 **Panel de Administración Protegido:** Control de acceso mediante PIN de seguridad con ocultación diferida.
* 🧾 **Emisión de Tickets Automática:** Visualización en pantalla y guardado dinámico de recibos dentro de la carpeta `/Tickets`.
* 📊 **Configuración de Impuestos & BD:** Adaptado a normativas con soporte para IVA (21%) e IGIC (7%), además de simulación de conexión a base de datos (SQL Server / PostgreSQL).

---

## 📂 Instalación y Ejecución Directa

No necesitas instalar el entorno de desarrollo .NET para ejecutar este programa.

1. Descarga o descomprime la carpeta **`TPVRestaurante`**.
2. Haz doble clic en el ejecutable **`TPVRestaurante.exe`**.

> 🔑 **Credenciales de Acceso por Defecto:**
> * **PIN de Administración Inicial:** `1234` *(se puede modificar dentro del panel de administración)*.
